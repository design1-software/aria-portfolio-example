## What this is

This repository is a **public example** of what an ARIA graduate leaves the program with: a set of
case studies produced on live systems, graded against an evidence rubric, and approved by a human
instructor.

It is not a certificate list and it is not a résumé. Every claim below is backed by the command
output that produced it.

> [!NOTE]
> This copy is **anonymized** — the graduate's real name is not shown, and secrets and
> lab-infrastructure identifiers are redacted. Everything else is the student's own work.

## How a lab earns its place here

Every case study passed a four-layer evidence pipeline:

| | Layer | What it catches |
|---|---|---|
| 1️⃣ | **Deterministic checks** | Empty, too-short, and placeholder submissions — rejected automatically. |
| 2️⃣ | **AI rubric grading** | Each required-evidence item scored against the lab's own checklist: satisfied yes/no, one-line reason, proving excerpt. |
| 3️⃣ | **Instructor review** | A human reviews the evidence, the rubric results, and the student's work. Only approved labs appear here. |
| 4️⃣ | **Sanitization** | Secrets and infrastructure identifiers redacted before export. What remains is real work, safe to share. |

> [!IMPORTANT]
> No lab reaches this portfolio without instructor approval. No secrets leave the platform.

### How to verify

Each case study ends with an **Approved Note** written by the reviewing instructor, plus the approval
date. That assessment is part of the artifact — it is written by a person, not generated or
templated.
